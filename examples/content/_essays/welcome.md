Apollo is a minimalist yet powerful theme designed for writers, researchers, and developers. It's built with Jekyll and focuses on typography, readability, and a clean aesthetic inspired by modern reading experiences.

## Typography

Apollo uses **Newsreader** for body text, a typeface designed specifically for on-screen reading. It pairs elegant serifs with a clean monospace font for code.

> "Typography is the craft of endowing human language with a durable visual form."

Headers are bold and distinct, while body text is set at a comfortable size with generous line height.

## Features at a Glance

*   **Responsive Design**: Looks great on mobile and desktop.
*   **Dark Mode**: Automatic theme switching based on system preference.
*   **Syntax Highlighting**: Beautiful code blocks for various languages.
*   **Math Support**: Render mathematical content easily.

## Images and Media

Images expand to fill the available width, maintaining a visual balance with the text.
