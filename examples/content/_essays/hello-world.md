Welcome to **Apollo**, a minimal and fast Jekyll template designed for personal websites and blogs. This post demonstrates the various content features available to you.

## Code Highlighting

Apollo supports syntax highlighting for code blocks.

```python
def hello_world():
    print("Hello, World!")

if __name__ == "__main__":
    hello_world()
```

```javascript
const greet = (name) => {
  console.log(`Hello, ${name}!`);
};

greet('Apollo');
```
